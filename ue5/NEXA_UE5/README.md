## Purpose

NEXA_UE5 is the high-fidelity Unreal Engine 5.8 presentation layer for the NEXA persistent simulated world.

## NEXA Core Authority

NEXA Core remains authoritative for:

- World state
- Simulation time
- Characters and relationships
- Economy
- Politics
- Events and consequences
- Mysteries
- Audience commands
- NIA memory
- NIA controlled actions

## UE5 Authority

UE5 is responsible for:

- High-fidelity city visuals
- NIA as a Tier 1 MetaHuman-quality hero character
- Visual NPC representations
- Environment rendering
- Character animation
- Facial animation and lip sync
- Cinematic cameras
- Audio playback
- UI and stream-facing presentation

## City Sample

City Sample is saved in the Fab library.

Its approximately 95 GB project download is intentionally deferred until Phase 14, when the NEXA district visual construction begins.

## Architecture Rule

UE5 must never become the permanent authority for NEXA world state. UE5 receives validated commands and presents the authoritative state supplied by NEXA Core.
